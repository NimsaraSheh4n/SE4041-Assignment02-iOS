# AI-Assisted Development Documentation

## Module

SE4041 - Mobile Application Design and Development

## Assignment

Assignment 02 - Part A

## Project

Smart Campus Navigator

## AI Tool Used

ChatGPT was used as an AI-assisted development tool during the planning and development of this project.

AI assistance was used to support the development process while the final project structure, implementation decisions, testing, documentation and submitted work were reviewed and managed by the student.

AI assistance was used for:

- Navigation structure

- Accessibility improvements

## Example Development Interactions

### Interaction 1 - Application Concept

**Prompt Summary:**  
Requested guidance for developing an iOS assignment using Windows without permanent access to a Mac.

**AI Assistance:**  
Suggested separating development into Windows-based planning/source preparation and final Xcode build/testing on macOS.

**Student Action:**  
Reviewed the assignment requirements and selected Smart Campus Navigator as the application concept.

## Validation and Review

AI-generated suggestions were not treated as verified final output automatically.

The following steps are planned before final submission:

- Compile the project using Xcode
- Resolve any compiler or runtime errors
- Test the application using an iPhone Simulator
- Test the application on a physical iPhone where possible
- Run unit tests
- Run UI tests
- Complete user acceptance testing
- Complete performance testing
- Update documentation using actual test results

---

## Limitations

The source code was initially prepared using a Windows environment where Xcode, SwiftUI runtime testing and iOS Simulator testing were not available.

Therefore, any sections marked as pending will only be finalized after actual Xcode testing.

## Academic Use Statement

AI was used as a development support tool for guidance, code suggestions, debugging assistance and documentation preparation.

The student remains responsible for understanding, reviewing, testing and presenting the final submitted work.
