# Smart Campus Navigator - Xcode Migration Checklist

## Purpose

This checklist describes the steps required to move the prepared Smart Campus Navigator source code into a real Xcode iOS project and complete final build, testing and deployment.

---

## 1. Mac Requirements

Before starting, make sure the Mac has:

- macOS supported by the installed Xcode version
- Xcode installed
- Internet connection
- Git installed
- Access to this GitHub repository

Optional:

- Physical iPhone for real-device testing

---
