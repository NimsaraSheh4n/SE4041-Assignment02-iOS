# Smart Campus Navigator - Project Plan

## Module
SE4041 - Mobile Application Design and Development

## Assignment
Assignment 02 - Part A

## Platform
iOS

## App Name
Smart Campus Navigator

## Purpose
Smart Campus Navigator is an iOS application designed to help university students quickly locate important campus facilities, view useful location information, and save frequently visited places.

## Problem
New students and visitors may find it difficult to locate lecture halls, laboratories, libraries, cafeterias, administrative offices, and other important facilities within a university campus.

## Solution
The application provides an interactive campus map with searchable locations, detailed place information, and the ability to save important locations for quick access.

## Target Audience
- University students
- New students
- Campus visitors
- Academic and administrative staff

## Main Screens

### 1. Home
- Welcome section
- Search
- Quick access locations
- Recently viewed locations

### 2. Campus Map
- Interactive MapKit map
- Campus location markers
- Selectable map annotations
- Location information cards

### 3. Saved Places
- Display favourite locations
- Remove saved locations
- Persistent storage using Core Data

### 4. Place Details
- Location name
- Description
- Category
- Map location
- Save to favourites
